✎ Đổi Tên Dự Án

Tự động tắt Studio (nếu đang mở), đổi tên thư mục, cập nhật project.json và chạy lại build.py để đồng bộ ID mới.

🎬 Xuất File `out/video.mp4`

Chạy python3 tools/render.py <id> ở chất lượng Full (1920×1080). Tiến trình sẽ hiển thị trực tiếp ở khung Nhật ký bên dưới.
